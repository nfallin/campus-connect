## User Requirements

- A user should be able to view the list of existing campus events, including each event's title, date, time, and location.
- A user should be able to see an event's contact email and/or website when the event has them.
- A user should be able to see a message indicating no events exist when the event list is empty.
- A user should be able to create a new event by entering a title, date, time, location, and hosting club.
- A user should be able to optionally provide a contact email and/or website when creating an event.
- A user should be able to see a newly created event appear in the event list immediately after creation.
- A user should be able to interact with the app as a guest without creating an account first.
